One official API serves everything: SingStat's Table Builder returns whole tables, so several series ride one GET — the opposite constraint from one-series-per-request providers. Its limit parameter caps cells per response and splits them across rows, so an underbudgeted request silently truncates history. The validator counts observations per row to catch exactly that.

Release calendar & staleness

Publication lag is not fetch latency. A print seconds old over the wire can still describe a month that ended weeks ago — in Singapore, usually about seven of them.
